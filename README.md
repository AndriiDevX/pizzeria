# pizzeria

A Flutter app for ordering pizza with firebase authentication.

## Features

- Browse pizza menu
- Add to cart
- Firebase Auth (login/logout)
- Order history
- Profile screen

## Tech Stack

- Flutter & Dart
- Riverpod (state management)
- Firebase Auth
- GoRouter (navigation)
